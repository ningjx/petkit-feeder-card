# Changelog

All notable changes to this project will be documented in this file.

## [0.3.0] - 2026-04-05

### Added
- Initial release
- PetKit feeder Lovelace card for Home Assistant
- Support for Fresh Element Solo (D4)
- Feeding schedule management (add/edit/delete)
- Feeding history tracking
- Manual feeding control
- Weekly view navigation

### Features
- **Feeding Schedule Management** - Visual weekly schedule management
- **Feeding History** - Track planned vs actual amounts
- **Manual Feeding** - One-click food dispensing
- **Status Monitoring** - Device status, WiFi signal, desiccant status
- **Interactive UI** - Click to edit time/name/amount

### Supported Devices
- Fresh Element Solo (D4) ✅
- Fresh Element (D3) 🚧
- Fresh Element Duo (D4s) 🚧
- Feeder Mini (Mini) 🚧
